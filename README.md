# Multimedia Retrieval

The textbook of the Multimedia Retrieval course at the University of Basel.

**Read online:** https://roger-weber.github.io/mmir-book/

This is the permanent home of the book: links to chapters and sections stay stable across semesters. Each chapter is published when it is ready; the PDF versions (per chapter, the whole book, a two-column edition and a summary and formula sheet) are available from the book's pages and under [`site/pdf/`](site/pdf/).

The semester repositories (demos, exercises, schedule) link here.

This repository holds the published site only. It is generated by the course's book tooling; please do not edit `site/` by hand.
